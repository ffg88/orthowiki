This is a template example for an markdown Article. The 3 tags above are mandatory in all articles, language should be "en" or "pt".

# H1 title
## H2 title
### H3 title

Each enter (linebreak) will be considered a paragraph.

Emphasis can be used by *italic* or _italic_. Strong emphasis by **bold** or __bold__.

> Blockquotes can be made this way.

`And code blocks this way.`

Unordered (bullet) lists can be made by *, + or -, like this:

- Item 1
- Item 2

And ordered (numbered) lists by number + .

1. First
2. Second

Multi-lines lists must use 4 spaces or tab before the next line

- First item

    Next line from the first item

- Next item
